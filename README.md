High School Management System
Project Overview

The High School Management System is a database project developed to help manage school information in an organised and efficient way. It stores and manages student records, teacher information, subjects, attendance, and academic marks.

The system is designed to make it easier for school administrators to manage school records and generate useful reports.

Project Objectives
To store and manage student information.
To manage teacher and subject information.
To record student attendance.
To manage student marks and academic performance.
To generate reports that support school administration.
Main Features
Add student records.
Update existing student information.
Delete student records.
Manage school information through the system interface.
Generate reports for school administration.
Reports

The system includes the following eight reports, each written in SQL and tested in MySQL Workbench:

Student Academic Performance Report – Shows each student's test, exam, and final marks per subject, with their class and grade.
Attendance Report – A full log of every attendance record, showing whether each student was present or absent.
Class Report – Shows the number of students in each class, with grade and academic year.
Subject Performance Report – Shows the number of students, average, highest, and lowest final mark for each subject.
Teacher-Subject Report – Shows which subjects each teacher teaches, with the grade level included.
Attendance Summary Report – Totals each student's attendance records, days present, and days absent.
Students per Grade Report – Shows the total number of students enrolled in each grade.
Students by Class Report – Lists the students in each class, including their student ID.
Technologies Used
MySQL – Database management and SQL queries.
Python – Application logic and connecting the interface to the database.
Tkinter – Desktop graphical user interface.
Database

The database stores information relating to students, classes, attendance, marks, subjects, teachers, teacher-subject assignments, and system users.
